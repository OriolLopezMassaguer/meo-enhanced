# 设置与输入

在右上角设置菜单选择“更多设置”，打开“常规 / 外观 / 输入 / 预览预设 / 快捷键”。左侧章节可以跳转，正文也可以连续滚动；搜索会筛选五个分类。设置保存成功后同步到其他面板，重新打开仍会保留。

小菜单保留常用文档显示选项及主题、语言、字号。行号开关控制左侧行号栏；工具栏“行号”用于跳到指定行，二者独立。

工具栏从“保存”到“重新加载”之间依次提供“另存为… / 撤销 / 重做”。另存为收集当前已确认的编辑内容，使用 VS Code 原生对话框保存；成功后继续编辑新文件，支持的 Markdown 文件仍用 MEO 打开。取消或保存失败保留当前文档。跨目录另存时保留 Markdown 原文，图片和相对链接按新文档目录解析。另存副本继续用于保存副本而不切换当前文档。

另存为保留本次编辑的阅读位置、Live / Source 模式和光标选区，新文件首次显示时接续原来的视图；关闭“恢复阅读位置”也不影响这次交接。取消或保存失败不改变当前视图。

撤销和重做使用当前文档的编辑历史，包括表格内尚未自动提交的已确认输入；没有对应历史时禁用，提示中的快捷键跟随用户绑定。窄窗口通过工具栏省略号访问收起的按钮。

取消另存为保持安静。VS Code 未返回保存目标时只记录“未完成”，不把原生保存失败推断为取消；磁盘、权限与覆盖冲突继续使用 VS Code 自带的恢复提示。MEO 收集或同步内容失败时，在编辑器内显示错误并提供“重试另存为…”和“另存副本”，重试重新读取最新内容。请求超时只提示结果尚未确认，提醒先检查对话框和目标文件，不自动重复保存。文件已保存但无法用 MEO 打开时，使用独立于旧面板的原生警告，提供“重试用 MEO 打开”和“用文本编辑器打开”；这些动作只打开已保存的目标，不重新写入文件。

撤销、重做的执行或焦点恢复发生异常时，保留诊断日志并显示可关闭的错误提示，提醒检查当前内容并提供另存副本。操作可能已经部分执行，因此不自动重放，也不提供盲目重试按钮；此规则同时适用于工具栏和快捷键。

## 输入

- 选中文字后输入符号可以包裹选区。覆盖 VS Code 原生 Markdown 的全部 11 组：`()`、`[]`、`{}`、`<>`、单双引号、反引号，以及 `*`、`_`、`~`、`$`；另外支持 `（）【】“”‘’《》「」『』`。内部文字保持选中，反向选区方向保留；连续输入可得到 `**文字**`、`__文字__`、`~~文字~~`、`$$文字$$` 和双反引号。内容中已有反引号时自动使用更长的界符；无选区时连续输入三个及以上反引号保留代码围栏。
- 包裹与空光标补全独立：新增的 `*`、`_`、`~`、`$`、`<>` 只包裹选区，不自动补出另一半，也不触发空对跳过或成对退格。选区前的反斜杠不阻止包裹。纯空格/Tab/换行选区、用英文引号替换单个引号/反引号，或多选区中存在不能包裹的选区时，整次输入按普通替换处理。规则参照 [VS Code Markdown 配置](https://github.com/microsoft/vscode/blob/645f29c/extensions/markdown-basics/language-configuration.json#L45-L90) 和 [原生选区包裹逻辑](https://github.com/microsoft/vscode/blob/645f29c/src/vs/editor/common/cursor/cursorTypeEditOperations.ts)。
- 补全、跳过和空对退格分别配置。默认按上下文补全，只跳过/删除自动插入的符号；“始终插入”和“只删除一个字符”保留逐字输入习惯。输入法预编辑期间不改写，确认后再处理；输入法已补整对时不重复。
- 列表和任务项默认按 Enter 续写，空项再按 Enter 退出。关闭后换行保留普通输入行为；表格内换行使用当前绑定的“单元格内换行”。
- Markdown 链接与图片路径按当前目录逐级补全，选择文件夹后继续选择下一层；`/` 从当前文档所属工作区开始，无工作区时从文档目录开始，远程工作区保留远程文件系统。菜单只显示单行名称，文件夹保留末尾 `/`、文件保留扩展名，不重复完整路径；默认字号下约 260px，大字号最多约 300px，窄窗口自动收缩，过滤和选中时宽度稳定。补全只替换当前路径段，保留前缀、已有锚点与链接标题；点击、导航和导出的根目录语义一致。Wiki 全库搜索继续显示名称与路径两行。
- 在 MEO 内跳转到 `.md`、`.markdown`、`.mdx`、`.mdc` 文档时，统一使用 MEO 打开并保留目标锚点；普通链接、引用式链接、Wiki 和 HTML 链接遵循同一规则。Live / Source 的链接文字使用 Ctrl / Meta + 点击，跳转按钮直接点击；完整与分栏 Preview 均可直接点击。Source 支持 HTML 链接地址和文字的跳转。其他文件使用 VS Code 文件关联，网页与邮件链接交给外部应用。
- Wiki 双链在当前 vault（最近的 `.obsidian`，否则所属工作区或文档目录）内搜索文件名、路径、别名和标题。支持按字符顺序的模糊匹配，多关键词必须全部命中；精确、前缀、单词边界、包含、模糊匹配依次优先，纯路径匹配靠后，同分时按目录距离、路径长度和路径稳定排序。先排序再取前 50 项。文件名结果先返回，frontmatter `title`、`aliases` / `alias` 或首个一级标题在后台补入；别名与标题匹配插入实际文件目标及显示名，同名文件插入最短无歧义路径。`[[/]]` 从 vault 根目录逐级选择，`[[./]]`、`[[../]]` 从文档目录选择。
- 标题候选支持井号标题、下划线标题及重复标题的独立锚点，插入实际锚点并保留 Wiki 别名。标题查询对当前文本限制为 2,000,000 字符，外部文件限制为 2,000,000 字节。上述补全也用于表格单元格，Wiki 别名分隔符在表格源码中自动转义，保持列数。
- 正文输入 `/` 可以选择常用块；链接、双链、图片、网址等地址上下文独占斜杠，候选关闭、无结果或查询失败时也不回退到块命令。表情名称候选默认关闭，开启后输入 `:name` 并选择才替换成 Unicode；未选择的 `:smile:` 保留原文。
- 所有输入候选菜单中，当前选中行的名称或辅助内容实际被截断时，自动显示完整内容气泡，无需鼠标悬停。多个截断字段合并为一个气泡，优先放在列表右侧、其次左侧；切换到未截断项、提交、Esc、失焦或菜单关闭时隐藏，保留编辑焦点与输入法按键。
- 选择目录后按 Esc 或移开焦点不会删除已输入的路径；再次把光标放回链接目标内，可以从当前目录继续选择。后台刷新不会自行重开已关闭的菜单。
- “候选菜单优先在上方显示”是斜杠、文档路径和表情菜单的共同开关，位于输入候选的三个启用选项之后；上方空间不足时自动换到下方，过滤时保持展开方向与选项顺序稳定。保留原 `slashPreferAbove` 设置键和已有值。输入法预编辑期间菜单继续过滤，拼音分隔符 `'` 只从当前输入段的查询中忽略，已输入的目录前缀、原文与插入替换范围保持完整；普通文件路径中的单引号仍按实际名称匹配。预编辑期间方向键、Enter、Tab、Esc 由输入法处理，点击候选也不会提前插入。

- 表格尺寸命令按“数据行 × 列”输入，支持 `/table6x4`、`/table6X4`、`/table6×4` 和 `/table6*4`，也可简写为 `/6*4`。未输入完整列数时菜单保持显示，补全后才可插入；非法或超出容量的尺寸不会插入默认表格。

## 复制与粘贴

“粘贴时保留常用格式”默认关闭。更新后首次加载会将已有用户和工作区配置中的此选项关闭一次；迁移完成后可手动重新开启，后续启动保留新选择。

| 位置/来源 | 行为 |
| --- | --- |
| 正文 + Excel/TSV/HTML 表格 | 开启表格转换时插入 Markdown 表格，第一行作为表头；关闭时保留文本 |
| 正文 + 含表格的混合 HTML | 同时开启 HTML 格式与表格转换时按原顺序保留正文、标题和所有表格；关闭任一选项时保留完整文本。结构块与目标正文保持边界；无表格的 HTML 不阻止 TSV 转换 |
| 已有表格 + 表格矩阵 | 从当前单元格覆盖并按需扩展；此行为独立于正文转换开关。支持编辑器自有格式、HTML、TSV 和 Markdown 表格源码 |
| 代码块或行内代码 | 保留文本，避免链接、HTML、表格转换 |
| 选中文字 + 网址 | 开启链接选项时用选中文字作为链接名称 |
| 正文 + 常见 HTML | 开启格式选项时转换支持的标题、列表、引用和行内格式；纯文本粘贴跳过转换 |
| CSV 文本 | 选择文本后执行“转换选中表格文本”，不自动猜测正文中的逗号 |
| 多选区 | 使用普通文本粘贴分发到各选区 |

普通表格复制同时提供文本、HTML 和编辑器自有数据，供不同目标选择。显式“复制为 Markdown 表格 / CSV”复制选区或当前表格的单元格源码；CSV 引号、换行和分隔符按 CSV 格式编码。HTML 合并单元格展开为空白占位，内容保留在合并区域左上格。批量表格操作上限为 10,000 个单元格，剪贴板解析上限为 5,000,000 字符。同一次混合 HTML 粘贴的所有表格共用容量；无效、超限或无法表达的嵌套表格会整次保留纯文本，不插入部分转换结果。

## 快捷键

快捷键分为文档、文字格式、段落、表格、选择、行操作、模式导航。除复制/剪切/粘贴和基础导航等系统规则外，可录入组合键、清除或恢复默认。未设置的命令可以自行绑定。

录入时 Enter 确认、Esc 取消，Tab 正常移动焦点；带修饰键的 Enter/Esc 可以作为组合键。冲突会列出原命令，必须明确点击“替换原绑定”。恢复默认只重置快捷键，其他偏好保留。工具栏和选中文字菜单提示随绑定更新。

默认粗体、斜体使用 Ctrl+B / Ctrl+I，macOS 使用 Cmd+B / Cmd+I；撤销、保存、查找等跟随平台习惯。表格专用命令只在表格内执行，块和行命令在文档编辑区执行。Preview 和设置/查找输入框不会触发正文格式修改。操作系统或 VS Code 先处理的组合键可能无法传到 Webview，应选择其他组合。

Windows 上在 Live / Source 文档编辑区单按左 Alt 会保持光标，不进入 VS Code 菜单栏；菜单仍可用鼠标打开。Alt 组合快捷键、右 Alt / AltGr、输入法和设置输入框保留原有处理，不新增配置。

这些设置位于 `meoEnhanced.editing.preferences`。已有工作区配置时更新该工作区，否则更新用户配置；多面板共享一个保存所有者，按字段合并并防止旧回执覆盖新值。
