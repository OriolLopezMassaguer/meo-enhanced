# 界面设计约定

这份约定记录已经确认的 MEO Enhanced 界面取向。设计新控件或调整现有控件时，先查看正在使用的组件和主题变量，再按这些规则处理；用户在具体任务中的新要求优先。

## 视觉与主题

- 以现有界面的圆角矩形作为主要形状。分段控件、菜单、对话框按钮保持同一套圆角和边距语言。开关保留目前的胶囊形状与切换动画，不加常态描边；内部圆点开启时固定白色，关闭时使用派生中性灰色，键盘焦点仍可辨识。
- 参考图用于提取明暗层级、选中关系和对比度，不直接复制其色值或尺寸。颜色跟随界面主题，浅色与深色都要检查。
- 文档预设配色与界面配色独立。只有内置“默认”预设可以跟随编辑器主题；GitHub 和自定义预设使用自身固定的浅／深色配色，内部变量及派生色也必须来自预设。自动模式只选择明暗方案。工具栏、菜单和设置面板继续从六个 UI 基础色选取或派生，不使用文档预设的颜色。
- 未选中的分段选项文字可以弱一些；悬停时只增强文字颜色，不增加悬停底色。键盘聚焦还应有可见的焦点标识。浅色模式要能清楚分辨普通与悬停状态，深色模式保持现有强度。
- 分段控件仅在上下和整组左右外边缘保留内缩，相邻选项的选中区域不留横向空隙；沿用共享组件的圆角、尺寸和切换动画。
- 工具栏单色图标继承文字颜色。具有格式含义的 HTML、PDF、Word 图标保留各自原色；图标内的透明镂空为白色，轮廓外透明。
- 单选按钮的选中圆点使用对比更强的强调前景派生色，避免用仅满足边界辨识的焦点色代替选中标识；低彩度主题通过明度差辨识选中状态，不强行改成另一种色相。
- 搜索与替换输入框使用 4px 小圆角和轻边线，聚焦时增强同一条边线；输入为空时隐藏清除按钮，有内容时显示，清空后再次隐藏。输入框内清除图标保持低强调，悬停时增强颜色和线条，不叠加遮挡内容或边线的底色。关闭整个搜索面板的按钮复用同排工具按钮的颜色、线条和悬停背景。高对比模式保留清晰边界和图标。

## UI 语义配色

新增或修改 UI 时，按“八项基础色 → 共同语义角色 → 组件”接入。颜色来源与通用派生逻辑统一由 `webview/src/helpers/uiTheme.ts` 管理，组件消费 `--meo-ui-*` 变量；基础色数量与语义角色数量分别计算。

| 基础色 | 默认 VS Code 来源 | 用途 |
| --- | --- | --- |
| 表面 `surface` | `editorWidget.background` | 工具栏底色，以及浮层、输入区域、交互背景和边界的派生基础 |
| 文档背景 `documentBackground` | `editor.background` | Live、Source 的文档底色；默认 Preview 同明暗时跟随，独立内容预设保留自身背景；目录跟随相邻文档视口 |
| 主文字 `text` | 工作台 `foreground` | 普通文字与单色图标，以及说明、禁用等前景层级 |
| 强调 `accent` | `button.background` | 主操作、开启、焦点和必要的强调标识 |
| 成功 `success` | `testing.iconPassed` | 成功反馈 |
| 警告 `warning` | `editorWarning.foreground` | 警告反馈 |
| 错误 `danger` | `errorForeground` | 错误反馈与危险操作 |
| 文字强调 `text-emphasis` | `textLink.foreground` | Live 标题、列表标记、链接，目录状态和候选匹配文字 |

用户配置优先。界面与 VS Code 明暗一致时读取宿主实际提供的颜色；明暗不一致或宿主缺值时，使用 `webview/src/themes/defaultUiColors.ts` 中对应的内置默认基础色。该文件保存 VS Code 1.138.0 的 Light 2026 / Dark 2026 八项输入快照，主题未定义的成功、警告色取该版本注册的默认值，并注明来源版本。只保存基础输入，继续共用语义派生与可读性校正；不在运行时解析另一套主题文件，也不增加预设选择入口。自动适配的普通文字和单色图标保持中性。组件不按主题名称维护色值，也不独立从宿主颜色或正文语法颜色取色。

- **共同表面**：工具栏与独立浮动按钮复用 `surface`；菜单、设置、搜索、候选、调色及表格操作弹层复用 `surface-raised`；输入区域复用 `surface-field`。浮层是表面派生角色，不是独立基础输入。大面积背景从共同表面调整明度、降低彩度，保持与菜单栏的关系；强调色只用于必要的操作和状态。
- **文档底色与派生**：`documentBackground` 与界面表面独立，不相互派生；浅色默认 `#FFFFFF`、深色默认 `#121314` 取自同版本 VS Code 默认主题的 `editor.background`。Source 保留原生语法前景及普通文档底色。Live 的代码块、Mermaid 容器、公式编辑区和 frontmatter 共用块表面；行内代码、行内公式编辑提示和属性标签共用行内表面。键盘标签 `<kbd>` 保持无填充，通过边框及按键外形辨认。表头、浮动表头与隔行填充共用更接近文档底色的表格表面，不能分别取色。行内代码在普通正文和有填充的表格行中都应可辨认；表格填充与行内底色保持足够区分，并以轻内边线辅助，不把行内代码做成强色块。深浅色强度以改造前 Live 的区分度分别校准；表格填充直接从文档底色派生，避免代码主题回退改变其层次。默认 Preview 透传同一组最终角色，验收以实际 Live 与 Preview 的承载面为准。
- **正文边线与块操作**：正文分隔线、表格网格、引用引导线、块内分隔线共用不透明的正文边线，保持轻量；frontmatter 的外框和内部行列线使用单独派生的块边线，浅色下增强与填充的区分，不联动增强表格网格。操作边界、键盘焦点另用更强的角色。块内按钮和语言标签使用按块表面校正的中性前景，常态透明，悬停/按下来自块表面派生；按钮弹出的菜单仍使用 UI 浮层角色。计算集中在 `uiTheme.ts`，组件不再自行挑宿主色或硬编码灰色。
- **正文预览与适配边界**：默认 Preview 与编辑器同明暗时复用文档底色与最终派生角色，异明暗和独立预设保留自身配对；已有导出样式环境传递最终角色，不复制派生算法。实时拖动沿用逐帧合并，仅投影 CSS，不重新解析文档或渲染 Markdown；应用时按最终背景刷新 Mermaid 标签配色，作者指定的图表色保持原样。代码前景检查复用已准备的配色，无法兼顾时保留代码主题承载面。背景与原生文字/明暗明显不适配时给出说明，不改用户 HEX 或自动切换模式。停止调整后合并并串行保存；关闭弹窗冲刷有效更改，保存失败明确提示并允许重试，重载恢复已保存值。具体映射与验收见 [文档表面配色方案](plans/document-surface-colors.md)。
- **前景配对**：普通图标继承相邻文字的 `text`；说明和占位文字复用 `text-muted`，禁用与选中状态采用对应前景。强调填充配 `on-accent`，小字强调用 `accent-text`，不把按钮底色直接当小字颜色。
- **目录配色归属**：固定与浮动目录共用布局规则：Live、Source 跟随各自文档；Source + Preview 左目录跟随 Source、右目录跟随 Preview；完整 Preview 两侧目录都跟随 Preview。切换期间跟随实际显示的相邻视口：准备中的新视图不提前接管，旧编辑器作为遮盖画面时保留其配色，待对应视口揭示后再更新。采用相邻视口的实际背景与前景，不按预设名称另写颜色，也不随焦点切换。标题栏、按钮、弱文字、悬停、可见范围、边线、拖动指示及滚动条共用目录局部角色；层级竖向引导线复用目录轻边线色，浅色下保持淡灰，不直接借用编辑器正文分隔线。强调色沿用最终内容强调并按实际背景与交互表面校正至至少 4.5:1。明暗、预设、目录位置和文档背景更新只投影样式，不重新解析文档；高对比保留可辨认的边界和键盘焦点。
- **文字强调**：Live 标题文字、列表圆点和编号、链接（含表格链接和脚注引用）复用 `text-emphasis-content`，列表正文保留普通正文颜色。标题前的 `#` 及标题内 Markdown 语法标记保留原有中性语法颜色，不继承标题强调色。脚注引用及定义编号的淡背景复用 `text-emphasis-background`，从同一基础输入降低不透明度派生，不新增可配置颜色。目录当前标题、悬停与键盘焦点也使用正文强调角色。标题前景按正文、行内代码和脚注淡底校正至至少 4.5:1；候选菜单的匹配文字和触发前缀以标题的最终色值为起点，普通与悬停行使用 `text-emphasis`，选中行使用 `text-emphasis-selected`。菜单背景上对比充足时保留标题色值，不足时仅做既有的最小对比校正至至少 4.5:1，不独立从宿主基础输入再派生，也不增加彩度或做鲜艳化处理；匹配字重和选中箭头辅助识别。派生色不独立配置。按钮、开关与焦点边界仍用操作强调，普通 UI 图标与文字仍保持中性。
- **状态派生**：普通悬停、按下和选中复用 `surface-hover`、`surface-pressed`、`surface-selected`。弱文字、输入底色和开关关闭态均由基础色生成，能派生的颜色不新增独立配置或持久化色值。局部降低强调可从已有角色混色；多处复用的关系收回统一生成入口。
- **表格编辑与框选**：Live 编辑单元格和多单元格选框共用内置浅／深蓝色 `tableSelectionBorder`，作为表格正文交互的配色例外，不跟随“操作强调”或“内容强调”。编辑框以 1px 细线直接覆盖单元格四边的网格线，不另画内框；深色将蓝色与文档背景按 80%／20% 混成不透明颜色，浅色保留完整蓝色，避免原网格线透出混色。多选外框保留完整色强度、1px 及同色淡底，区分编辑和选择状态。高对比模式下两者共用宿主焦点色，编辑框保持 1.5px 和完全不透明；不新增独立颜色设置。
- **浅色弱块操作**：代码块、Mermaid、公式块的常态附属操作文字/图标可使用较弱的共同前景，以自身块底色校正至至少 3.5:1。这是用于降低常态强调的局部例外，不作为普通小字的可读性标准；悬停/键盘焦点使用既有强前景，深色与高对比模式不跟随弱化。
- **块背景层次**：以原 `documentLayer(dark ? 0.10 : 0.055, 1.12)` 为基准，与文档背景做 OKLab 回混；深色保留 75% 的原色差，浅色保留 60%。1.12 仅作为原基准的下限，不能再把最终背景推回原强度。文字与代码前景保护继续生效；frontmatter 共用块背景并同步减淡，行内和表格填充各自独立。
- **边界分工**：分割线用 `separator`，浮层轮廓用 `border-float`，需要清楚辨识的控件边界用 `border-control`，键盘焦点用 `focus`。轻边线可以复用浮层轮廓角色，聚焦时增强；边线与分割线保留所属表面色系，不统一硬编码为灰色。
- **模式与对比**：浅色、深色共享角色名称，派生参数可以不同；混合后按实际承载表面校正前景对比。高对比保留宿主明确的边界、焦点和选中配对，并用轮廓、线条或标记辅助辨识状态。
- **外观对比提示**：文档背景的对比不足或代码底色保护提示采用紧凑文字与前置警示三角；标记复用 `warning`，文字复用 `text`，以 `surface-field` 轻底色区分普通说明，不加描边或侧边装饰。用户自定义同色时仍能通过图形辨识提示。
- **适用范围**：这套角色适用于外围界面、文档底色及上述 Live 文字强调用途。其余正文、Source 原生语法着色、Preview 内容预设、文档色样，以及本文已明确的说明气泡、格式图标和开关白色圆点保持各自约定；新增例外需明确用途并记录在本文件。八项基础输入可在“设置 > 外观”配置：常用的界面背景、文档背景、界面文字、操作强调、内容强调直接显示；成功、警告、危险置于高级分组。每项留空时按实际来源显示“跟随 VS Code 主题”或“默认浅色 / 深色配色”，恢复按钮及搜索词保持一致。浅色与深色的覆盖项分别保存到 `meoEnhanced.appearance.colors`，内置默认值不写入用户配置；不修改全局 VS Code 主题。手动输入保留用户选择，跳过自动中性化，仅进行既有可读性校正；高对比度优先使用宿主规则。派生色不独立配置。

实现新元素时，先确定表面、前景、边界和交互状态，再复用上述角色及现有控件。确有多处共同需求且已有角色无法表达时，在统一入口增加派生角色，并在这里补充用途与复用范围。完成后检查深浅色、中文英文及普通、悬停、选中、键盘焦点状态；具体验证范围仍按当前任务授权执行。

## 控件与排版

- 设置弹窗的“外观”页依次提供界面模式、文档排版、基础颜色和高级颜色。字号从常规页迁入文档排版，菜单保留字号快捷入口；行间距只在弹窗提供，直接显示字号倍数，每次调整 0.1，支持恢复内置默认 1.5 倍，不增加“默认／自定义”模式。行间距用于 Live、Source 和默认 Preview，独立预览预设保留自身排版。
- 外观设置即时生效并保存，不提供“应用／取消”。颜色拖动继续逐帧合并投影，停止调整后合并持久化请求；有效更改在关闭时冲刷，无效 HEX 不覆盖已保存设置。保存请求串行执行，延迟回应不能覆盖后续选择；失败显示说明和重试操作，恢复默认颜色清除浅深色覆盖项。
- 外观和快捷键的恢复默认按钮统一右对齐，按钮行仅占右侧内容列；左侧章节定位栏延伸至弹窗底部，不被按钮行横向截断。

- 回到顶部按钮属于所在文档视口：Live、Source 取各自文档背景和正文前景，Preview 取预设最终背景与前景，分屏时分别跟随各自视口。准备中或作为过渡遮盖的不可交互视口隐藏其按钮，待视口可以交互后随其一起显示，仍按实际滚动位置决定是否出现。三种视图共用细边线、悬停和按下的派生规则；明暗、文档背景和预设变更随现有 CSS 角色同步，键盘焦点保留清晰边界，高对比模式增强边框。

- Preview 正文和留白支持与外部控件一致的全局快捷键，使用当前用户绑定及平台规则。完整 Preview 和 Source 侧边 Preview 均保持全局作用域；选字、复制、滚动、正文输入控件与输入法保持原行为，不向其他编辑器转发编辑、撤销或全选命令。

- Preview 优先处理 MEO 当前绑定的全局命令，未处理的真实命令按键沿用 VS Code 的 Webview 键盘通路，由宿主解析用户绑定及组合快捷键。原生阅读和输入操作保留在正文；转发事件不重复执行 MEO 命令，不硬编码命令中心的快捷键或命令 ID。

- 所有分段控件由 `webview/src/adapters/segmentedControl.ts` 创建，开关使用 `webview/src/adapters/menuSwitch.ts`；共同样式集中在 `webview/src/styles.css`。调整共享外观时先改共同来源，再检查特殊尺寸的使用处。
- 分段控件选项之间不留人为间隙，同一控件的选项等宽。左右外边缘的内距由整组容器统一保留，选中背景横向铺满所在选项，仅在上下内缩；文字与选中背景在同一区域内居中，首尾选项不单独缩进。切换时文字位置固定，选中块只横向平移，宽度和圆角不变；始终播放原有 150ms 滑动动画，不受系统或 VS Code 的“减少动画”偏好影响。
- 分段文字先裁掉字体行框的额外留白，再按当前字形的上下边界修正居中，兼顾中文回退字体和英文下伸笔画，不为各个选项写固定偏移。文案、字体、字号或像素密度变化时由共享组件更新；选中状态不改变文字位置，图标独立居中。观察器与字体监听随控件销毁释放，完整设置重绘时同时清理旧控件。
- 分段控件默认按内容自适应宽度，各选项以最宽内容为基准等宽；需要稳定对齐时指定总宽，外边缘内距包含在总宽内，剩余空间平均分配给选项。文案、字体和字号变化时自动宽度随内容更新，指定总宽保持不变。右上角模式切换在中英文之间保持同宽。短文案优先，例如“开 / 关”。
- 布局优先紧凑，但不能靠裁切标签换取宽度。中文和英文标签都保持单行；图标、文字、控件的左边界与右边界要有规律地对齐。行高按内容决定，只有开关的行无需沿用分段控件行高。
- 按钮宽度随文字变化，高度、文字内边距和圆角参照调色弹窗中的“取消 / 应用”。同一横幅里的强调、普通、关闭按钮尺寸协调；强调按钮用反色，普通按钮用中性边框，关闭按钮保持低强调。

## 说明气泡

- 共用气泡由 `webview/src/adapters/tooltip.ts` 创建，外观集中在 `webview/src/styles.css`。Bootstrap 用 `bindTooltips(document.body)` 统一接入动态控件及 Preview 内文档；控件提供 `data-tooltip`，可选 `data-tooltip-shortcut`、`data-tooltip-kind` 和 `data-tooltip-placement`（方向值为 `top`、`bottom`、`left`、`right` 之一），不再写原生 `title`。直接创建组件使用 `createTooltip(anchor, { content, placement, focusTarget })`，其中 `placement` 和 `focusTarget` 可省略；显式参数优先于 DOM 元数据，未指定方向时自动定位。多状态按钮用 `data-tooltip-live-update="true"` 或 `createTooltip` 的 `liveUpdate: true` 显式启用实时更新。需要将信息图标与所在按钮的键盘焦点关联时传入 `focusTarget`，所属控件销毁时调用 `dispose`。
- 保留需要辨认的纯图标、功能额外说明、被截断的名称或路径全文，以及文档作者提供的说明。删除重复可见文字和明显不必要的提示；关闭、清空等通用按钮保留无障碍名称，不重复显示气泡。分段控件不默认提示选项名称。
- 定位参考点通过 `positioning: 'element' | 'pointer'` 或 `data-tooltip-positioning="element|pointer"` 指定，默认 `element`；直接创建组件的参数优先。方向偏好继续使用 `placement`。`pointer` 在首次约 200ms 延迟后随鼠标位置更新，默认位于鼠标右侧 12px、向下 8px，靠近边缘时平移或翻转，与可见边界至少留 8px，并沿用菜单避让。位置更新按动画帧合并，不重新等待或加入拖尾动画；Preview 使用所属 iframe 的客户区坐标和可见边界。键盘聚焦按组件定位，滚动后鼠标已不在有效目标内时关闭。这是既有气泡的定位方式，不增加额外导航浮层。
- 浮动表头使用 `pointer` 提示“点击回到表头 / Click to return to table header”；Source 分栏的手动视图对齐按钮使用普通按钮的默认 `element` 定位，提示“将预览对齐到源码视图 / Align preview to source view”和“将源码对齐到预览视图 / Align source to preview view”。表头列宽拖拽区域不显示导航气泡；目录宽度拖动处不显示气泡，保留无障碍名称及原有操作。
- 链接及其跳转按钮的气泡统一使用中文“跳转到：”或英文“Go to: ”前缀，地址与锚点不翻译；URI 编码的中文等内容显示为可读文字，保留编码的 URI 分隔符，非法编码保留原文。该格式化仅用于气泡，不修改实际跳转目标。外部链接保留完整地址、参数和锚点，页内跳转显示 `#锚点`，不重复链接文字或目标标题；文档作者提供的说明保留在目标之后的下一行。跳转按钮的无障碍名称继续描述操作。
- Live 正文、HTML 和表格链接文字普通悬停不提示，Ctrl / Meta 悬停显示目标并使用手形光标；额外 Alt / Shift 保持编辑与选择行为。鼠标静止时按下修饰键也应显示，松开立即隐藏。表格进入编辑状态后按当前文字和鼠标位置识别链接，普通文字、空白及 Markdown 标记不提示。跳转图标无需修饰键即可提示和点击，修饰键不改变其气泡。Preview 正文和表格链接文字普通悬停即可提示，修饰键不改变提示与直接跳转行为。
- 链接目标气泡按内容自适应宽度、最大 320px，短内容不强制留白；空间不足时按所在可见区域左右各保留 8px 后收缩。宽度不绑定正文链接文字、图标或单元格宽度。内容左对齐，长地址达到上限后完整换行，高度随内容增加。正文可编辑 mark 的属性由编辑器管理，气泡关联稳定的编辑器根节点。链接沿用共同的 200ms 延迟、单一显示、定位与退出规则。
- 鼠标稳定悬停约 200ms 后显示，键盘聚焦使用同一气泡；同一时间只显示一个，切换目标取消旧计时。普通按钮点击时关闭；启用实时更新的多状态按钮操作时保留提示，文案变化且鼠标仍在同一按钮上或按钮仍有可见键盘焦点时立即刷新，不重新等待 200ms。离开、Esc、窗口失焦、控件消失或滚出可见区域时关闭；关闭后的内容更新不自动唤回，须重新悬停或键盘聚焦。滚动和窗口尺寸变化重新定位。
- 连续鼠标查看时，已显示气泡离开后 500ms 内进入其他有效提示立即显示，每次离开已显示气泡重新计算窗口。首次查看、超过窗口或尚未显示就快速扫过时仍等待 200ms；无提示目标不延长窗口。点击（包括多状态按钮）、Esc、Tab、窗口失焦、控件失效和所有者销毁结束连续查看；多状态按钮当前气泡的实时更新仍保留。键盘聚焦继续使用首次延迟。共用组件统一维护状态和计时，Webview 与 Preview iframe 一致。
- 除下述列表全文提示外，未指定方向时按上、下、右、左顺序寻找完整可见的位置。指定 `placement` 时优先显示在该方向，不可用时先尝试相反方向，再按默认顺序尝试其余方向。靠近窗口边缘先平移，再换方向；与边缘至少留 8px，与控件间隔 6px。方向是偏好，不是允许裁切或遮挡的锁定位置。避让其他展开菜单及进入菜单的路径；空间不足时菜单操作优先，隐藏提示。菜单栏的标题入口及其级别菜单、带悬停菜单的插入表格入口，以及分栏的联动和更多图标指定 `right`；文档内普通表格的菜单入口和操作按钮保持自动定位，不指定方向；指定方向的提示以控件自身的可见范围为锚点，菜单内提示不以整个菜单为边界，可浮在所属菜单表面上。
- 外层不带箭头，10px 圆角，13px 字号、400 字重、18px 行高，内边距上下 4px、左右 8px，最小高度 28px。浅色主题背景固定 `#0d0d0d`，深色主题背景使用中性灰 `#3a3a3a`，文字统一 `#ffffff`；两种主题均使用局部灰度渲染，无描边。浅色主题无外阴影；深色主题加 `0 3px 10px rgb(0 0 0 / 40%)` 的深色轻阴影，让气泡与背景区分。气泡沿用所属文档、窗口或模态界面的语义层级。
- 修复多行间距时，以现有按钮提示样式为基准，不另定圆角、内边距、字体或颜色。内容测量仅作用于需要换行的气泡：按原有最大宽度排版，再按实际最长行和字形上下界确定内容尺寸，保持原有行间距并垂直居中。上下留白须计入按钮最小高度提供的额外空间：从现有最小高度减去外层上下内边距，得到单行内容区；再按当前字体的单行字形高度推导对称留白，应用于整个多行文字块，不能只保留 CSS 内边距而让多行显得贴边。短内容不被最大宽度撑出空白。普通按钮及快捷键标签沿用原来的排版和字体修边。测量节点在组件创建时建立并持续复用，定位期间不得反复插入、移除节点，以免触发 DOM 监听循环。
- 操作提示描述点击后的动作，省略“当前为……”“点击即可……”“再次点击将……”等状态解说和口语化引导。同一按钮的多种模式使用同一种句式：视图切换统一“切换为分栏 / 切换为源码 / 切换为预览”，开关统一“启用…… / 关闭……”，翻页统一“上一页 / 下一页”。必要说明直接表达原因或限制；重新加载等风险操作必须保留“放弃未保存内容”等关键后果，不以缩短文案为由省略。
- 控件拥有提示文案；初始化、语言切换、模式切换沿用同一来源。快捷键刷新只更新按键标签，不把控件文案覆盖为另一套命令名称。文案不得嵌入 `Ctrl+S` 等手写快捷键，提示和快捷键必须对应同一个实际动作。
- 中文和英文同步维护，保持动作及状态含义一致。英文使用句首大写的短语，保留 HTML、Mermaid 等名称的正确大小写；不混用多套术语。同一功能在各模式下的名称保持一致。
- 中英文界面文案需要省略号时，统一使用单字符 `…`（U+2026），紧接文案、不加空格，不混用三个句点 `...` 或中文正文的 `……`。另存为、导出为、自定义预设、选择文件夹等既有入口，以及加载、生成、保存等进行中提示均遵循此规则。
- 短提示默认单行、宽度随内容变化；`kind: 'fulltext'` 只在文字截断时显示全文，文件名、路径及被截断内容不做文案精简。`kind: 'description'` 用于必要说明，允许按可用空间换行；不按字符数硬截断必要信息。全文、说明及链接沿用 320px 最大宽度（含内边距），空间不足时继续收缩；达到上限后完整换行，连续数字、长文件名和地址也允许换行，不为全文提示单独取消宽度上限。对齐方式沿用原有规则，不在修复测量时重设。
- 目录与输入补全列表中的全文气泡默认优先显示在整个列表右侧，空间不足时翻到左侧，垂直对齐所属文字行，避免遮住相邻项和同一行的其他列。两侧均放不下时再尝试上下位置，保留完整内容和边界、菜单避让规则；显式方向与鼠标定位优先于该默认规则。输入候选由当前选中项自动触发，按实际 DOM 截断测量，不等待悬停；截断的名称、路径或说明合并为一个气泡，内容保持完整换行与 320px 上限。不改变普通提示的 200ms 悬停及 500ms 连续查看规则，不抢焦点或输入法按键。
- 快捷键来自当前实际有效绑定，跟随用户改键和平台变化，必须对应按钮的实际动作；多个绑定优先显示一个。无绑定不显示标签。快捷键沿用现有控件的 12px 字号、400 字重、16px 行高，标签内边距上下 2px、左右 6px；浅色主题标签背景使用 `#555555`，深色主题使用 `rgba(255, 255, 255, 0.18)`，使标签与外层气泡有清楚的层次；整体放在一个 6px 圆角标签内，与正文垂直居中，不拆成多个按键框；到气泡上、下、右边缘均留 4px，与内外圆角差一致。
- **全文提示或需要换行的提示不得同时出现快捷键。** 内容类型将两者分开，组件不自动拆开、删去绑定或把按键拼进长说明。出现实际冲突必须列出具体控件并另议处理方式；调用方更新语言或绑定时同步更新内容。移除视觉提示时保留必要的无障碍名称。

## 设置与工具栏

- 工具栏的普通动作、开关和菜单入口共用禁用、悬停、按下及键盘聚焦反馈。可用态保持清晰的中性前景，关闭的开关仍可点击，不额外叠加透明度；禁用态使用 `text-disabled`，不响应悬停和按下。悬停、按下分别复用 `surface-hover`、`surface-pressed`，按下不额外添加描边或内阴影，松开后恢复当前状态；开关已开启或菜单展开时持续使用 `surface-selected` 及配对前景，关闭后恢复。键盘聚焦独立显示 `focus` 轮廓，分段控件保留原有外形。另存为执行期间保持原图标并临时禁用，沿用既有防重复触发逻辑，结束后恢复，不单独显示转圈或忙碌底色；重载待确认使用实心红底（`#bc4b42`）与白色确认图标，悬停和按下保持同一配色、不加描边，保留既有二次确认流程。
- 文档内的表格操作入口与弹出工具栏沿用菜单栏的状态反馈。禁用按钮不叠加透明度，图标徽标随禁用前景；列对齐选中态保留成对的选中底色与前景，键盘聚焦独立显示轮廓。按下底色比悬停有更明显的明度变化，高对比模式同样通过填充区分，不增加描边或内阴影；松开后恢复普通或选中态。鼠标按住期间保留当前单元格与文档，松开时触发操作，拖出按钮再松开取消；键盘操作沿用现有路由。新增、删除徽标保留既有语义颜色。
- 表格结构页的“删除表格”常态使用红色图标；首次点击原位展开为红底白字“删除表格”，3 秒内再次点击确认，超时、切换页面或关闭菜单恢复图标。展开与收回使用短宽度动画，减少动态效果时直接切换。排列页的升序、降序紧接对齐操作，“上一页”仍在末尾，翻页名称保持“上一页 / 下一页”。排序按当前列比较显示内容，表头保留，整行移动，空值始终在末尾，同值保持顺序，支持撤销。
- 编辑工具栏的文档操作顺序为“保存 → 另存为… → 撤销 → 重做 → 重新加载”，其后继续使用原有分隔线与格式工具。按钮沿用统一尺寸、单色图标、语义配色及中英文提示；撤销和重做提示显示实际有效绑定，无可用历史及操作进行中时禁用，完整 Preview 不提供编辑历史操作。窄窗口沿用既有工具栏溢出菜单，移动原按钮并保留状态与监听。另存为使用原生文档保存流程，保存成功后在新路径继续编辑；另存副本仍保留原有用途。
- “另存为…”在快捷键设置的文档组中紧接保存，默认使用 `Ctrl + Shift + S`（macOS 为 `Cmd + Shift + S`）；已有其他命令自定义占用该组合时保留用户绑定。录制、改绑、清除、冲突处理和恢复默认沿用现有机制。它属于全局命令，Live、Source 与 Preview 共用按钮的另存为流程及防重复触发逻辑；按钮提示仅显示当前有效绑定。
- 文档操作错误使用既有可关闭提示和明确的恢复动作；取消不报错，原生保存错误保留宿主自身的恢复通知，不重复弹窗。结果未知用警告说明先检查文件，不自动重试；已保存但打开失败必须明确保存已成功，只提供打开目标文件的动作。撤销、重做异常提示检查当前内容并可另存副本，避免重复回放可能已部分执行的操作。
- 设置按“文档显示 / 打开文档时 / 界面设置”等清楚的功能组组织。标题应直接说明结果，英文也用常见短语，避免抽象缩写。设置行采用左侧图标和单行标签、右侧控件的结构。
- 设置菜单维持紧凑宽度，同时完整显示英文标签。分段控件与字号步进器的左右边缘对齐；分隔线维持菜单内部的短线样式。
- 普通选项不加无意义的悬停提示。确实需要解释的选项，在标签旁放信息图标，悬停图标才显示提示；提示层要盖过相邻行和控件。点选设置值后菜单保持打开，以便连续调整。
- 预览工具栏顺序为“预设 → 正文字体 → 代码字体 → 预览主题 → 代码着色 → HTML 注释 → 正文宽度”。入口名称为“预设”，内置默认项叫“默认”。预设入口作为一个完整的选择器强调：单一中性表面和细边框，左侧调色盘图标及“预设”文字使用 `accent-text`，不增加内部描边、底色或独立徽标。通过统一内距、标题与当前名称之间的留白、当前名称的字重形成层次；普通状态复用 `surface-field`，悬停复用 `surface-hover`，展开复用 `surface-selected`，完整焦点描边仅用于键盘聚焦。菜单选项的图标表达各自预设：默认使用打开的书本图标，GitHub README 使用 GitHub 标识，选中勾跟随中性色文字。保持工具栏共同高度与圆角，悬停或展开时使用中性色轻微增强，键盘聚焦才显示完整焦点描边。弹出菜单保持轻量浮层，使用单行图标、名称与选中勾，选中背景克制。预设说明使用选择框右侧的信息图标，与选择框作为一组移动到窄屏更多菜单或分栏菜单。分栏菜单中，顶部预设选择框撑满该行剩余宽度，说明图标并排保留。默认、GitHub 和自定义预设共用控件及说明规则：所有配置项保持显示，可修改项正常编辑，固定及不支持项禁用并提供限制说明；固定值同时在预设说明中列出；单主题的明暗控件保持显示并禁用，整段控件触发随鼠标定位的限制说明。说明先显示作者文案，再用分隔线列出主题支持、注释、代码着色、字体和正文宽度的配置规则；不展示当前明暗或用户开关状态。预设失败时说明图标变红，错误标题前也显示红色图标并列出原因。默认预设保留原有设置；GitHub README 显示完整配置项，仅主题可修改，字体、代码着色、HTML 注释与正文宽度按预设禁用，正文宽度固定为最大宽度内自适应。注释选项使用“显示 / 隐藏”，英文为“HTML comments · Show / Hide”；新用户默认隐藏。
- 导出入口使用“导出为…”与随主题变色的导出图标，英文为“Export as…”。菜单包含 HTML、PDF、Word 各自的普通版和含目录版，沿按钮左边缘展开，表面颜色沿用表格按钮的悬停菜单。鼠标悬停时立即显示菜单，离开按钮和菜单区域 300ms 后关闭；重新进入时取消关闭计时。选中导出项、点击外部或按 Esc 立即关闭；键盘焦点仍在菜单内时保持展开，点击入口不应使菜单常驻。
- 可调整的明暗、字体、代码着色、HTML 注释和正文宽度按预设分别记忆，切换预设及打开新文档后恢复；默认预设继续使用已有全局设置。支持明暗两种主题的预设首次选“自动”，单主题使用支持的主题；预设定义不另行指定双主题的初始明暗。
- 预览选项在完整 Preview 和 Source 分屏均点击展开；再次点击入口、外部点击或 Esc 关闭。鼠标离开、内部焦点变化及设置变更不关闭；子列表先处理 Esc，关闭后返回字体入口，再次 Esc 关闭外层选项。字体搜索接入既有输入焦点恢复规则，输入法确认不选择字体。
- Source 分栏 Preview 左上角的联动和更多按钮共用圆形外观，不因联动开关或菜单展开而增加选中底色、内描边；保留共同的悬停、按下和键盘聚焦反馈。联动状态继续通过图标、提示和无障碍状态表达。
- Source 分栏关闭同步滚动时，在两栏分割线的垂直中间固定显示一个 26px 宽、48px 高的竖向胶囊，上方右箭头、下方左箭头；图标画布保持 22px，横杆缩短并居中。两个直径 23px 的圆形点击区上下相切，分别贴住胶囊两端，悬停、按下和内缩的键盘焦点均按圆形显示，圆外角落不触发对齐。开启同步滚动、关闭分栏或进入完整 Preview 时隐藏。胶囊共享一层较弱的 `border-float` 外框，底色、边框、图标及交互状态均复用外观设置的 UI 语义配色，不读取两侧文档配色，高对比模式增强外框。仅圆形命中区域响应操作，不扩展正文留白的点击范围，也不引入分割线拖拽行为。
- 右箭头以 Source 当前视口顶部阅读位置为准对齐 Preview，左箭头以 Preview 当前视口顶部阅读位置为准对齐 Source；共用既有源码行和块内位置的语义映射，文档边界自然截断。每次只滚动目标侧，不改变参照侧的视口、Source 光标和选区、输入焦点、横向滚动或同步偏好；键盘触发保留按钮焦点。后续滚动仍然独立，重新开启同步时以最近明确操作的一侧为准。预览尚未准备好、内容过期或没有可映射内容时禁用两个按钮，恢复后重新可用，不显示忙碌状态。不再提供随光标或悬停内容移动的定位按钮及其悬停块底色，已有编辑位置标记独立保留。
- 正文与代码字体使用同一系统字体目录及搜索选择器；输入只过滤结果，点选或 Enter 才提交；选择后立即应用并保存，保留列表、搜索词和滚动位置，焦点回到搜索框，便于连续比较。还原默认也保留列表；Esc、外部点击或切换入口关闭。清空搜索按钮平时使用细线与弱前景，悬停或键盘聚焦时增强，仅清除筛选并保持搜索焦点。搜索输入区域内右侧固定并排显示“默认”“刷新”两个带常规外框及圆角的小型文字按钮，不使用图标，默认操作在前；悬停提示和无障碍名称分别使用“还原默认字体”“刷新字体列表”；操作不参与过滤、不随结果滚动。还原仅移除当前正文字体或代码字体的覆盖，恢复默认预设的默认字体或当前预设原有字体；已使用默认字体时禁用还原按钮。系统字体按家族去重并支持已有别名；中文界面优先显示系统明确提供的中文家族名，没有则保留原名，搜索同时匹配原名、别名及本地化名称；显示语言变化不改变保存的家族标识。当前选择缺失时保留并说明。首次打开按需加载、会话内共享缓存，刷新失败保留已有列表；远程 Host 不列出服务器字体。字体控制策略同时约束正文和代码，内置 GitHub README 两项均显示并禁用，显示“由样式决定”及限制说明。
- 字体菜单打开时确定横向锚点，选择字体、筛选及刷新期间保持横向位置，关闭后再次打开才按当前入口重新定位；窗口缩小时仅作保持可见所需的边界修正。字体菜单采用紧凑单行列表，搜索与两个操作按钮共用顶部一行；长名称省略并沿用全文气泡。选中项只保留轻底色，不附加勾选标记；当前字体继续显示在入口。字体结果区最多展示十四个普通行高，超过后滚动，视口不足时继续缩短；搜索和操作按钮始终可见。滚动条预留宽度、轨道透明，悬停或焦点位于菜单内时显示细窄圆角滑块，颜色复用 UI 滚动条角色。
- 正文字体与代码字体分别记忆；代码字体只覆盖行内代码与代码块的字体名称，字号、行高与布局继续由各自样式负责。预设未调整字体时保留原样，HTML/PDF 使用同一字体规则。
- 预览字体的选择框及其弹出菜单使用与导出菜单相同的主题表面颜色，边框使用与预设入口一致的中性色，下拉箭头使用说明文字颜色，保持可见。
- 预览工具栏下拉菜单的相邻选项至少留出 1px 间隔，目前统一为 2px；预设、字体、宽度与导出菜单复用同一条规则，选中和悬停背景不要连成一片。
- 下拉菜单高度按实际内容和视口上下可用空间计算，包含选项间隔、内边距、边框及底部动作；不使用固定像素高度上限。空间足够时完整显示，空间不足时在空间较大的一侧展开并滚动。
- “变更”菜单中的选项不使用整行悬停提示；若确有无法从标签表达的必要说明，应在标签旁放信息图标，并仅在悬停图标时显示。

## 交付检查

检查中文和英文、浅色和深色，以及普通、悬停、选中、键盘聚焦状态。确认文字不换行或裁切，切换时文字不移动，菜单和提示不被遮挡。纯文案、替换既有图标和局部纯样式按 `docs/testing-workflow.md` 的轻量 UI 边界完成构建或类型检查、基础视觉及受影响控件的功能冒烟，复用有效证据；行为变化仍按常规快速与定向门禁验证。

## 完整设置窗口

- 完整设置窗口与小设置菜单共用菜单背景和边框配色，文字、图标和共享控件保持一致的明暗层级。
- 小菜单维持 288px，六项文档显示开关及原有主题、语言、字号控件；完整窗口入口分组叫“更多设置”，左侧使用调节滑杆图标和“外观与编辑”，右侧“打开设置”按钮进入完整窗口。英文对应 More settings、Appearance & editing、Open settings，保持单行布局。
- 完整窗口使用“常规 / 外观 / 输入 / 预览预设 / 快捷键”五个 Tab、左侧章节导航和连续滚动正文。侧栏分类名称保持单行，栏宽按完整文案适配，中英文与窄屏均不换行。搜索框与“设置”标题同排，按窗口中线居中；两侧保留标题和关闭按钮的位置，窄屏收缩搜索宽度。标题行与 Tab 行保持紧凑间距。窗口标题保持简洁，Tab 独占下一行并使用统一字号和常规字重，以选中颜色和下划线突出当前分类。说明保持简短，二选多选优先展开单选选项，避免下拉菜单。
- 章节标题可放大加粗；侧栏选中使用中性色。Tab 使用强调色，标签下划线贴住分隔线且不覆盖数量徽标。搜索图标始终可见，非空输入显示中性清除按钮；聚焦只改变一像素边框颜色。
- 小菜单开关保留整行交互。完整窗口开关只点击控件本体，正文行不加悬停底色；单选本体与标签有一致的小手光标。主题、语言、字号只有右侧控件可交互。
- 快捷键 Tab 的底部恢复默认动作使用确认浮层，不改变窗口尺寸。外观 Tab 的颜色编辑提供实时预览、应用、取消和恢复默认颜色；恢复默认同时清除两种明暗配色，仍需应用才保存。取消、关闭或销毁窗口恢复已保存颜色；保存失败保留草稿并显示错误。模式沿用立即保存行为，文案与颜色草稿动作明确区分。冲突替换使用既有红色文字，必须明确点击；恢复默认保留其他设置。
- 普通设置行保持紧凑，大分类之间增加间距并用分隔线收尾。完整窗口的主题、语言、字号控件同高、右侧对齐；自动字号下整个步进器禁用，保留上次自定义值。
- 每个 Tab 都保留左侧章节导航与右侧连续设置项，导航从当前可见章节生成，搜索后保持对应关系。外观页分为界面模式、基础颜色和高级颜色，不另加卡片外框或额外折叠层。每行左侧标题与说明、右侧选项；颜色圆点与 HEX 输入组合成一个控件，深色无常态边框，浅色保留从共同浮层边界派生的一像素内侧轻边线，避免输入底色与面板同色时失去轮廓。悬停和聚焦使用一像素内侧线，颜色圆点的键盘焦点也保持在内部，高对比模式保留清晰边界。重置使用有无障碍名称的图标按钮。模式切换复用小设置菜单的分段组件、短文案及明暗图标，外观页右侧控件列为 240px，分段、颜色输入及重置按钮统一 32px 高和 8px 外圆角；窄屏空间不足时允许控件移到下一行，标签保持单行。
- 设置动作按钮统一高度和内边距，宽度按文案变化；小菜单的“打开设置”仅显示文字、不带箭头，保留适中的独立尺寸，小菜单宽度不变。设置搜索框复用共同输入区域的语义配色和不透明底色，避免组件自行灰阶处理与窗口背景产生偏色观感。
- 搜索同时匹配每项设置的中英文名称、说明、选项值和常用同义词，不受界面语言影响。多个词须在同一项中全部匹配；快捷键按当前实际绑定检索。输入时保留搜索框焦点，五个 Tab 的结果数量使用同一套匹配规则。
- 设置项的搜索词按稳定 ID 集中维护在 `webview/src/application/settingsCatalog.ts`。新增、删除、重命名或修改设置项时，同步维护对应的中英文词条，覆盖常用叫法、功能结果和关联术语，并核对名称、说明、选项值及当前快捷键都进入索引。完成前确认设置与命令清单的关键词覆盖完整，并在两种界面语言下验证名称、代表性别名及结果数量一致。
- 搜索清除和窗口关闭使用 SVG 图标及方形点击区域，清除按钮与搜索框垂直居中，关闭按钮与搜索框中线对齐；图标在按钮内部水平、垂直居中。
- 从文档打开完整设置后，通过 ×、窗口外部或 Esc 关闭均恢复原编辑位置和焦点，包括表格原生单元格；Preview 中返回设置入口。
- 搜索、替换和设置搜索各自保留光标、选区方向与输入框内滚动。离开窗口再返回时优先继续当前可用输入框，不重新全选；主动关闭面板后沿用正文恢复。正文位置由编辑器保留，主动搜索跳转、替换或新点击产生的位置优先。隐藏、禁用或销毁的控件不恢复；输入内容改变时不还原旧内容或旧选区。恢复不能抢走其他页面或模态控件的焦点，Preview 的正文继续只读。
- 外观连续取色时，色样和 HEX 值立即反馈，配色派生按动画帧合并并只处理最新草稿；颜色预览仅更新 UI 语义角色，不重复写入正文配色与字号。不要将预览结果重复回写到原生色样输入。应用和模式切换先处理最新草稿，取消、恢复默认、关闭和销毁必须撤销待执行预览，避免迟到的颜色覆盖结果。

## 输入候选弹窗

- 斜杠、文档、路径、标题、表情及公式候选共用紧凑外框，继承编辑器字体、圆角、阴影、选中态和滚动条。斜杠左侧英文命令，右侧随界面语言变化的简短说明；表格命令用 `NxN` 提示可输入尺寸。
- 公式候选左侧固定显示标准插入模板，补入部分统一使用弱文字，不添加占位符或首个参数强调；实际插入的智能去重不改变展示。右侧用现有公式渲染器显示固定示例，复杂环境使用紧凑结构示意。预览限制在行内，不撑高选项；默认 13px 编辑器字号为 28px 等高行，较大字号随普通候选的文本行高统一增长。示例只用于辨认，不写入正文；说明保留在无障碍名称中。
- Wiki 全库文档搜索使用双行选项：第一行显示名称、别名或标题，第二行左对齐显示路径，两行使用同样宽度，弹窗沿用约 360px。逐级路径补全只显示单行名称，不重复输入中已表达的目录；文件夹保留末尾 `/`，文件保留扩展名。默认 13px 字号下宽约 260px，随编辑器字号放宽至最多 300px，窄窗口与分栏继续按可用空间收缩；不随过滤结果或选中项改变宽度。长内容省略显示，选中项实际截断时自动提供全文气泡，逐级路径的气泡只显示完整名称。标题保持单行，右侧显示锚点以区分同名项；表情使用更窄的单行弹窗，左侧显示 `:name:`、右侧显示表情。斜杠、文档、路径、标题、表情及公式候选共用选中项全文规则；切换到完整项、提交、Esc、失焦、离开可见区或所有者销毁时关闭。匹配文字沿用文字强调色。
- 普通明暗主题的斜杠、文档、路径及标题候选名称复用 `text-strong`；右侧说明、下方路径及参数由 70% `text-muted` 与共同表面混色，辅助内容中的匹配片段也按同样比例降低强调。两者从基础文字色与共同表面派生，避免对比度校正后变成同色。表情菜单沿用原有文字与图形颜色，表情保持完整不透明度。主次层级在悬停和选中时保持稳定，高对比主题保留原有前景配对。
- 选中行背景贯穿弹窗宽度，左侧保留细双箭头标记的位置。普通明暗主题仅用底色和标记区分选中态，主文字、辅助说明及匹配片段在选中前后保持各自配色；匹配的斜杠和字母以 Live 标题的最终文字强调色为起点，仅在承载面上对比不足时做必要校正。高对比主题沿用选中背景与前景的配对规则。
- 滚动条始终预留同样宽度，轨道透明，仅悬停菜单时显示圆角滑块，整体裁切在弹窗圆角内。
- “候选菜单优先在上方显示”复用现有开关，同时控制斜杠、文档路径、表情和公式菜单，放在对应启用项之后。按完整行数选择展开侧，空间不足时回退到另一侧；首项靠近偏好侧边缘，过滤和空间回退不改变固定顺序。输入法预编辑时保持菜单，忽略拼音查询中的 `'`，保留原输入长度及目标路径；候选临时不可提交，按键留给输入法。
- 以输入的 `/` 为锚点跟随文档滚动；空间不足时切换上下位置或缩短列表。锚点离开编辑区或单元格的可见范围时关闭，同一查询不因滚回而重新打开。


## HTML 片段

- Live 中块级 HTML 平时显示渲染结果；单击普通内容或光标导航进入时，展开主文档源码，上方源码、下方实时结果，离开后收起。源码与结果使用同一块底色和连续外框，中间轻分隔，结果左上角标注“预览 / Preview”；无可见结果时只包围源码，不增加空预览。不提供独立的右侧编辑或预览按钮。拖拽选字（含块内注释）、折叠和 Ctrl / Meta 打开链接保留阅读操作，临时失焦和操作下方预览保持编辑位置。注释按普通文本选字，不增加独立的按钮焦点，键盘经主文档光标进入源码。
- 无可见结果的独立片段保留原始源码，统一复用文档注释前景 `--meo-token-comment-color`，保持正常源码字号和行高，不做多色语法强调，不加底色。光标进入后恢复正常源码着色；离开后仍无结果则恢复注释色。图片加载中、分隔线和有尺寸的色块按实际结构呈现，可见容器内部的空节点随该容器源码查看。
- 预览只从原文派生，编辑辅助不进入 Preview 或导出；HTML 注释保留既有规则。常见文档标签与有限行内样式共用校验规则，GitHub 预设保留自身策略。未完成源码保持可编辑，源码显隐和渲染更新沿用文档的选区、历史与阅读锚点。
- 行内 HTML 随所在行进入和离开编辑，不在段落下增加独立预览。HTML 标签和属性补全复用主编辑器，候选沿用共同表面、文字、边界与选中角色。

## Live 块浮动头

- 代码块、Mermaid 和公式块的头部滚出编辑区顶部时，语言和按钮吸顶；同一编辑区只显示吸顶线所在块的头部，宽度跟随块可见范围。剩余内容不足一行头部高度时退出，避免覆盖后续正文；短块不吸顶。
- 头部使用代码块的不透明背景自然遮挡内容，不加底部分隔线，保持紧凑高度。浮动时按钮始终可见，沿用现有图标、顺序、主题颜色、悬停强调和气泡提示。
- 只有按钮可操作；语言和空白区域使用默认箭头，不能编辑、选择或拖动，也不能点击穿透到正文。滚轮继续滚动编辑区。
- Mermaid 在源码、分栏、预览模式下共用头部；模式按钮使用固定切换图标和当前模式短文字，循环“预览 → 分栏 → 源码”，保持固定宽度。公式使用主文档直接编辑，点击或光标进入时展开上方源码、下方结果，离开后收起源码，不提供手动块内模式按钮。
- Live Mermaid 和块级公式在“复制源码”左侧提供“复制为图片”，覆盖普通与吸顶 Mermaid 头部，以及公式阅读和源码编辑状态。图片只复制当前有效结果；源码模式没有图形、渲染中或结果过期时禁用图片复制。
- 图片复制的禁用状态随初次挂载、渲染完成、错误、编辑及恢复自动同步，不依赖悬停或点击刷新。灰色仅表示当前没有可复制的有效结果。
- 只有存在预览时提供缩放、复位和全屏，窄宽度沿用已有更多菜单。Mermaid 图表操作位于图块可见区域的右下角，高图滚动时仍留在屏幕内；悬停图表或键盘聚焦时显示。模式状态、复制内容和缩放状态以实际块所有者为准。同一图块编辑、历史回放和模式往返保留缩放与平移；复位、更换图表类型或删除重建时恢复默认。
- 导航、搜索和光标揭示避开头部遮挡。全屏、编辑器模式切换、块删除和销毁时隐藏或清理头部。表格浮动头仍沿用整行点击导航。

## Preview 块操作

- Mermaid 右上角按“全屏查看 / 复制为图片 / 复制源码”排列；所有块级公式按“复制为图片 / 复制源码”排列，不增加公式全屏。普通代码块只有“复制源码”，行内公式保持原有阅读与选字交互。Live 的块级源码复制使用相同名称。
- 操作沿用块内中性前景、悬停和键盘焦点样式，悬停图块或聚焦操作时显示；按钮不随图形缩放。渲染中或失败时，保留源码复制，禁用需要有效渲染结果的操作。
- 操作条只因悬停或可见的键盘焦点保持显示；鼠标留下的逻辑焦点不使其常驻，也不触发提示气泡。鼠标进入全屏时焦点放在查看器上，退出恢复入口逻辑焦点但不画焦点框；键盘进入和退出保留清晰焦点提示，Tab 与 Shift+Tab 在查看器内循环，切换回鼠标操作时同步清除旧焦点提示。
- 图片复制生成完整 PNG，跟随当前内容配色，包含不透明背景和少量留白，排除语言标签与操作控件；公式保留当前换行和编号，裁掉正文行宽带来的无关空白。图形查看时的相机不影响复制范围；成功反馈以剪贴板写入完成为准，失败就近提供可见反馈，不回退成源码或 SVG 字符串。
- Preview 与 Live Mermaid 使用同一全屏查看交互：占满编辑器区域、初始适应内容、指针中心缩放、拖动平移、复位、关闭按钮及 Esc 退出。退出恢复原阅读位置和入口焦点，查看相机与正文相机独立。全屏操作条只放缩放、复位与退出，不放复制按钮。

## 预览预设管理

- 预设下拉菜单底部固定“自定义预设…”导航动作，前置加号图标，并复用上方预设菜单行的尺寸、圆角、文字、图标和悬停样式；分隔线放在选项列表与导航动作之间，不作为按钮描边。该动作不会成为当前预设，键盘可进入列表和管理入口。
- “预览预设”页只管理可用性，不标记或切换当前选择。只有默认始终启用，列表复选框保持勾选并禁用；其他内置及自定义预设勾选表示在预览菜单显示，内置预设不能移除。隐藏或移除正在使用的预设时回到默认。
- 列表和 Preview 工具栏复用同一个预设说明组件，展示作者提示和相关配置。两处都只展示配置规则，不展示当前明暗或用户开关状态；固定值属于预设配置，可以列出。分割线上下使用相等间距和一致的文字行盒。
- 预设下拉菜单通过整行悬停或键盘聚焦，在选项右侧立即展示说明与配置，气泡上边与选项上边对齐；移到另一项时同步更新，离开或关闭菜单时收起。右侧空间不足时优先使用左侧，并按窗口空间避让菜单；选项不附加信息图标，只有点击或确认选项才切换预设。此顶部对齐仅用于预设下拉菜单。
- 预设列表共用一个圆角外框，每项保持单行，名称与简短标识并排。右侧信息图标复用说明组件，自定义项在信息图标后直接并排放置导出、移除图标按钮，保留悬停提示和无障碍名称，不使用更多折叠菜单。导入和指南按钮保留文字，并在文字前添加统一尺寸的图标。
- “导入预设”和“制作指南”使用有外框的普通按钮，图标置于文字前；“导入预设”不带省略号。
- 移除图标下方显示紧凑确认浮窗，复用面板配色；仅点击浮窗内“移除”才执行。取消、Esc、点击外部或离开管理页关闭浮窗，不弹系统确认框。界面文案保持简短，不重复说明原始文件保留。
- 导入采用文件夹选择、校验后复制，保留原件。相同 ID 更新和移除均确认；更新保留显示状态，导入不自动切换预览。导出和移除仅用于自定义项。制作指南按面板语言在浏览器打开仓库的 `preview-presets/` 目录内文档。
- 窄屏下预设页收起章节侧栏，保留完整列表和操作空间；其他设置页沿用原导航。
- 新增管理控件继续使用六个基础色及共同语义角色，不从预设正文 CSS 取色。列表、按钮、复选框和信息图标检查中英文、深浅色、窄屏及键盘焦点。
